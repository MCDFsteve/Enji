# macOS：可选面板与下载状态

日期：2026-11-12。

## 范围与最终设计

在当前 Apple Silicon Mac（macOS 27.2，26B123）构建并启动 SwiftUI 原生应用，通过生成的 CLI 操作实际界面绑定，并截取、查看应用自身窗口。

最终采用用户确认的简化方向：

- 下载中：原生下载图标自上向下填充主题色。
- 下载成功：换成应用已有的 `folder` 本地图标，名称「在本地」，使用普通次要前景色；不叠勾、不加圆底、不保留主题色。
- 完成标记是非交互状态图标，不再提供重复下载按钮。
- 手机和桌面播放页的声明同步修改；本次只在 Mac 实际运行。

## 测试隔离

使用 `target/diagnostics/macos-player-features/home` 作为独立 HOME、`/tmp/enji-mac-features` 作为 IPC 目录。音量为零，未读取或复制日常账户 cookie，下载文件只写入测试 HOME。截图仅覆盖测试应用窗口。

使用 Bern 提交 `8e95c39cae4098c5fec6decfd6cdfc479c8508ca` 的生成器和运行时构建。没有将临时本地依赖写进仓库。

## 构建中发现并解决

最初两处按钮在 `label` 中直接嵌套条件式 `tr!`，声明编译器拒绝。最终两个状态各自使用静态本地化文案，已通过完整 Mac 构建，不再需要条件式或 plural 文案。

构建仍有已有的 unused local patch 提示和 `BernRubyDocument` 的 Sendable 警告；它们未阻止构建。本轮未调整这些无关代码。
